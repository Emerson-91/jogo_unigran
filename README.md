# Unicão na Feira das Profissões

## Descrição
O Unicão na Feira das Profissões é um jogo educativo em Pixel Art executado diretamente no navegador. O projeto foi desenvolvido especialmente para a feira de profissões do Centro Universitário Unigran Capital, utilizando o mascote da instituição, o Unicão, para interagir com futuros acadêmicos e apresentar os cursos e as oportunidades do ambiente universitário.

Este repositório serve como modelo prático para as disciplinas de Engenharia de Software, ilustrando conceitos de gerência de configuração, hospedagem estática e portfólio profissional.

## Tecnologias Utilizadas
* Linguagem: JavaScript (HTML5 Canvas / Vanilla JS)
* Estrutura: HTML5 e CSS3
* Hospedagem: GitHub Pages
* Design Visual: Assets customizados em Pixel Art (Mascote, NPCs e Cenários)
